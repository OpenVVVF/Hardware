# HW-C3-FR-CSP-A — Chassis Cornerpost

Bent 3 mm 5052 aluminium angle cornerpost for the DC/DC converter module
frame. Qty 4 per module; the hex-punched holes take McMaster 90720A550 rivet
nuts (pressed in after fab, 2 per post). Shares geometry with the Chassis 3
front frame (source body in `../../DC-DC-Module.FCStd`, `Chassis-Frame` >
`Chassis-Cornerpost`).
